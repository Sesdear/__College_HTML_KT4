# Турагентство «Даль» — КТ 4

Адаптивная версия готового сайта турагентства. Проект использует HTML и CSS, установка зависимостей не требуется.

## Просмотр

Откройте `index.html` в браузере. Для проверки мобильной версии включите режим устройства в инструментах разработчика и установите ширину 375 px.

## Что сделано

В конец `css/style.css` добавлен медиазапрос `@media (max-width: 768px)`:

- логотип расположен по центру, меню — под ним в столбец;
- уменьшены заголовок и отступы первого экрана;
- поля поиска расположены друг под другом, кнопка занимает всю ширину формы;
- направления и преимущества расположены в один столбец;
- колонки подвала расположены в столбец и выровнены по центру.

Исходные HTML, изображения и десктопные правила CSS сохранены. Задание и мобильный макет находятся в этой же папке.

## Загрузка в репозиторий

Загрузите содержимое этой папки в публичный репозиторий: `index.html`, `css/`, `img/`, этот README, задание и макет. На учебный портал отправьте ссылку на репозиторий.
